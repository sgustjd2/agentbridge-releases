# AgentBridge KR 배포 저장소

Windows용 **AgentBridge KR**의 설치 파일을 배포하는 저장소입니다. 소스 코드는 포함하지 않습니다.

- 설치: [Releases](../../releases/latest)에서 `AgentBridge-KR-Setup-<버전>.exe`를 받아 실행하세요.
- 업데이트: 설치된 앱이 시작할 때 이 저장소의 최신 릴리스를 확인해 새 버전을 내려받고, 종료할 때(또는 알림의 "지금 다시 시작") 설치합니다.
- 설치 파일은 코드 서명이 되어 있지 않아 Windows SmartScreen 경고("추가 정보 → 실행")가 나올 수 있습니다.
